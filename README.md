# André Luiz — Arte e Pinturas

Site profissional para apresentação de serviços de pintura residencial e comercial.

## Tecnologias
- HTML5
- CSS3
- JavaScript puro

## Executar localmente

Na pasta do projeto, execute:

    python3 -m http.server 8001

Depois, abra no navegador:

http://localhost:8001
